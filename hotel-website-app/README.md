# 🏨 Hotel Website Concept

A modern, premium, and fully responsive hotel website concept designed to demonstrate how a strong digital presence can help hotels showcase their rooms, amenities, and services while making it easier for potential guests to make booking enquiries.

This project was developed as a hospitality website prototype and sales demonstration for a hotel business in Jos, Nigeria.

> ⚠️ **Disclaimer:** This is a concept website created for demonstration and pitching purposes. It is not the official website of the hotel unless otherwise stated.
